📄 PDF Question Answering Tool

Project Overview

An AI-powered tool that allows users to upload PDF files, ask questions, and get answers based on the document's content.

Features

- Upload PDF documents.
- Extract text from PDFs.
- Ask questions and get answers.
- Save time with intelligent document search.

Technologies

- Python
- AI / NLP
- Google Colab

How to Run

1. Open the notebook in Google Colab.
2. Install required libraries.
3. Run all cells.
4. Upload a PDF and start asking questions.
